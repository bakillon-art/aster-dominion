# Backend

Servidor autoritativo del MMO Aster Dominion.

## Responsabilidades

- autenticación y cuentas
- imperios y planetas
- producción offline
- construcción
- flotas y combate
- escombros y reciclaje
- alianzas y chat

## Stack inicial

- Node.js
- TypeScript
- Express
- PostgreSQL cuando se conecte la base de datos
- Redis para colas y temporizadores
