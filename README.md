# Aster Dominion

Juego MMO de estrategia espacial original para Unreal Engine, con presentación 3D premium, combate cinematográfico, economía persistente y universo compartido.

## Objetivo

Construir un universo compartido donde cada jugador controle un imperio con planetas, flotas, investigación, alianzas, espionaje, combate y reciclaje de escombros.

## Estructura del proyecto

- `docs/` visión y diseño del juego.
- `backend/` servidor autoritativo del MMO.
- `client/` base técnica del cliente Unreal.
